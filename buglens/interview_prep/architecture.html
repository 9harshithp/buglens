🐞 BugLens — Architecture

Defect Quality Checker · v1.0 · Streamlit + Python + FastAPI + OpenAI

🎨 Presentation Streamlit

7-field form, sidebar sample loader, Plotly score chart, issues expander, downloadable rewrite, JSON debug view.

🧠 Application Python

5 single-responsibility modules: validator, scorer, rewriter, analyzer. Pure functions, dataclasses, type hints.

🤖 Intelligence OpenAI (opt.)

GPT-4o-mini for the rewrite. Graceful local fallback when no key is set — the demo never depends on a network call.

🔌 Service FastAPI

REST surface: /health, /analyze, /validate, /score. Auto OpenAPI spec.

📦 Data JSON / dataclass

5 curated sample defects in data/sample_defects.json. DefectReport is the source-of-truth contract.

🧪 Quality pytest

18 tests across 4 files. Validator, scorer, rewriter (with and without API key), end-to-end pipeline.

🔁 Data flow — one analyze call

1 User submits the form (or API receives JSON)  →  payload
2 DefectReport.from_dict(payload)  →  normalised report
3 validator.validate(report)  →  List[ValidationIssue]
4 scorer.score(report, issues)  →  QualityScore (0–100, grade, verdict, sections)
5 rewriter.rewrite(report, issues)  →  RewriteResult (text + suggestions + grammar notes + mode)
6 analyzer bundles everything  →  flat JSON the UI / API returns

📐 Design choices called out

✓ Rule-based scoring as the source of truth. LLM is a *booster* on top.

✓ Rewriter degrades to a deterministic local path. Demo never breaks.

✓ DefectReport dataclass is the data contract — DB can drop in later.

✓ Single-responsibility modules: each one is independently testable.

⚠ No auth, no DB, no history. Deliberate v1 cuts — see Roadmap in README.

⚠ Grammar check is rule-based; the LLM-driven grammar hook is wired but disabled by default.
